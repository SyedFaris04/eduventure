# Audio credits

Every recorded sound here is **CC0 (public domain)**: free to use, change and sell, with no credit required. We credit the
authors anyway, with thanks. Each file was levelled (music to -16 LUFS, effects to a -6 dB peak) and converted to MP3.
To swap one, keep its file name (or edit `manifest.json`); a sound missing from the manifest falls back to the code version.
