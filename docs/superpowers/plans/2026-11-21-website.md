# Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An interactive one-page website at `https://syedfaris04.github.io/eduventure/` (English and Malay) showing the game in 3D, with a live demo question and an APK download section. It is published with the game by the existing workflow.

**Architecture:** A second Vite entry (`vite.site.config.ts`, root `site/`, base `/eduventure/`, output `dist-site/`) builds a small React page. The page imports the game's 3D code (`HeroScene`, `buildMonster`, `buildPet`, `hasWebGL`) but not its i18n, Supabase or router. `scripts/pages-bundle.mjs` puts `dist-site/` at the Pages root, beside `play/`.

**Tech Stack:** React 19, Vite, Tailwind 4, R3F, drei, three (all installed), and `qrcode` (a dev dependency, used once to make a committed SVG).

**Spec:** `docs/superpowers/specs/2026-11-21-website-design.md`

## Global Constraints

- **Links:** the APK is `https://github.com/SyedFaris04/eduventure/releases/latest/download/eduventure.apk`, and the game is `play/` (relative to `/eduventure/`).
- **Languages:** English and Malay only. Every key exists in both.
- **3D:** only when `hasWebGL()` and not `prefers-reduced-motion`. Each scene loads when it scrolls near the screen and stops drawing when off-screen.
- **No fakes:** no invented player counts, ratings or reviews.
- **The game's behaviour stays the same:** `HeroScene`'s new props default to the current behaviour.

## Review Focus

- **First paint on a slow phone:** text and buttons must show before any three.js downloads. Check: the site entry chunk doesn't contain three.js; the 3D is in lazy chunks.
- **No WebGL or reduced motion:** every 3D section shows its still version, and "Hit" and "Evolve" still respond. Covered by unit tests of the fallback components.
- **The language switch:** every visible string changes, and the choice survives a reload. Covered by the dictionary test and `check-pages`.
- **Broken links:** every download button and QR code points to the release URL. Covered by the links test.
- **The game at `/eduventure/play/` and its deep links still work** after the root changes. Covered by `check-pages`.
